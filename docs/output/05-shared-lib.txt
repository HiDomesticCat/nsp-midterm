
==== the library is a shared object ====
$ file build/lib/libpmon.so
build/lib/libpmon.so: ELF 64-bit LSB shared object, x86-64, version 1 (SYSV), dynamically linked, BuildID[sha1]=d09ebace816b2d776dae7e604b19202b6817c12a, not stripped

==== functions it exports ====
io_read_full		log_init		proto_op_name
io_set_sigpipe_guard	log_set_debug		proto_recv
io_write_full		log_toggle_debug	proto_send
kv_get			log_write		proto_status_name
kv_get_num		pmon_crc32
