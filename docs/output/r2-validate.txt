
==== WITHOUT the mechanism (--no-validate) ====
'GET / HTTP/1.1' is read as a header: bytes 4-7 '/ HT' = 0x2f204854,
a payload length of 790,644,820 bytes (754 MiB). The child allocates it and waits.
$ build/bin/pmond -p 9419 -t 6 --no-validate    (pid 65303, log in /tmp/pmond-demo.log)
$ curl -m 4 http://127.0.0.1:9419/
one second later, children of the server:
  child 65313  state S  756 MB  pmond
curl exit code: 28   (28 = gave up after 4 s without any answer)
server log:
  (nothing - the server did not notice anything wrong)
